# Snowie Client

Fabric client mod for Minecraft 1.21.11. Java 21 required.

## Build on GitHub (no local Gradle installation)

1. Create a GitHub repository and upload the contents of this project (the files inside `SnowieClient`).
2. Open the repository's **Actions** tab.
3. Select **Build Snowie Client** and click **Run workflow**, or push a commit to `main`/`master`.
4. When the run finishes, open it and download the `SnowieClient-1.0.0` artifact.

The workflow uses GitHub-hosted build tools; nothing needs to be installed on your Windows PC.
